# A1 candidate angles + DESIGNER deliverable spec

Sibling of [`AAP_OBJECTIVE.md`](AAP_OBJECTIVE.md). Split out per AT0 point-fix 5: these are
authored design seeds, not objective content, and must not sit inside the artifact AINV-12
byte-checks at ATF. Amendable; the objective is not.

## Candidate angles for A1 (three independent bets)

- **D1 evidence-index:** the page is an index of evidence. Each project is presented by its
  single strongest verifiable claim plus the number or artifact that proves it; structure
  follows what can be proven, not what looks balanced.
- **D2 craft-demonstrator:** the implementation is itself the work sample, as climx's is.
  Spend climx's machinery deliberately — router, per-project routes, the living styleguide,
  the 404 shim — so that reading the repo is part of the portfolio.
- **D3 editorial-single-page:** the madebyevan.com tradition the operator named as reference —
  one dense typographic page, near-zero UI furniture, each project a short honest note.
  Minimum machinery, maximum reading.

Declared handicap, stated openly rather than smuggled: D3 forgoes climx's router, the pool's
highest-value resource, so it carries the burden of reaching M6 ≥ 4 by other means. This is a
handicap on the angle, not a thumb on the scale at A3 — the judges score all three against the
same frozen metrics.

## DESIGNER deliverable (what each A1 context returns)

1. A complete design across the objective's three axes (page structure · evidence model ·
   climx reuse depth).
2. The exact climx files it ports, each with `from` → `to` and what changes in adaptation.
3. A per-metric self-estimate against M1–M6 with the instrument named for each. Self-estimates
   are claims; A2 recomputes them first-hand.
4. A scope budget that closes under E8: route count and new-file count under `src/`, listed.
5. Staged milestones, each ending runnable and measurable.
6. Its own honest weakest point.
7. Its `contentGaps`: anything it needs that does not exist on disk. A design with zero
   honest gaps is suspicious.
