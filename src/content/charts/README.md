# Chart files

One `phyriad-chart/1` JSON per chart, named `<project-slug>--<chart-id>.json` (for example
`phyriadfg--frame-budget.json`). The shape and the rules are in `figure-contract/README.md`;
`src/lib/charts.test.ts` validates every file here with `figure-contract/validate-chart.mjs`.
There are none yet: the three project sessions are gathering their data. The page shows a visibly
provisional line until a project has one.
